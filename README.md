## 📌 About
AquaSense AI is a web-based flood safety platform built for Malaysia. It combines a Random Forest ML model trained on Malaysian flood data (2000–2010) with an interactive map, community flood reporting, shelter finder, and AI-generated safety guidance.

Built with **React + Vite + Firebase + Leaflet**.
